# Практична робота №10
## Менеджер завдань із резервним копіюванням (Hive + Export/Import)

**Варіант:** 6

**Тема:** Робота з файловою системою та локальним збереженням даних у Flutter.

### Мета роботи

Ознайомитися з використанням локального сховища Hive у Flutter, навчитися організовувати збереження та обробку даних, реалізувати експорт та імпорт інформації у форматі JSON, а також створити систему резервного копіювання й аналітики.

### Завдання

Розробити мобільний застосунок для керування завданнями з можливістю локального збереження даних та резервного копіювання.

Відповідно до варіанта необхідно реалізувати:

- модель завдання з назвою, описом, датою виконання, пріоритетом, статусом та списком підзавдань;
- локальне збереження завдань за допомогою Hive;
- додавання, редагування та видалення завдань;
- фільтрацію за пріоритетом і статусом виконання;
- сортування завдань за датою виконання;
- створення резервних копій у форматі JSON;
- імпорт та відновлення завдань із JSON-файлів;
- автоматичне щоденне резервне копіювання;
- перегляд і видалення резервних копій;
- формування аналітичної статистики виконання завдань.

### Використані технології

- **Flutter** — розробка мобільного застосунку.
- **Dart** — основна мова програмування.
- **Hive** — локальна база даних.
- **JSON** — формат експорту та імпорту даних.
- **path_provider** — отримання директорій файлової системи застосунку.
- **file_picker** — вибір файлів для імпорту.

### Реалізований функціонал

#### 1. Керування завданнями

- створення нових завдань;
- редагування наявних завдань;
- видалення завдань;
- позначення завдань як виконаних або невиконаних;
- встановлення пріоритету: низький, середній або високий;
- встановлення терміну виконання;
- додавання та видалення підзавдань;
- фільтрація та сортування списку завдань.

#### 2. Локальне збереження

Для збереження інформації використовується Hive. Робота з даними організована через окремий репозиторій `TaskRepository`, який забезпечує CRUD-операції та обробку списку завдань.

#### 3. Резервне копіювання

Реалізовано окремий сервіс `BackupService`, який забезпечує:

- створення резервних копій у форматі JSON;
- перегляд наявних резервних копій;
- видалення резервних файлів;
- імпорт даних із JSON-файлів;
- автоматичне створення щоденної резервної копії під час запуску застосунку.

Автоматичне резервне копіювання перевіряє наявність копії за поточну дату під час запуску програми. Воно не виконується у фоновому режимі після закриття застосунку.

#### 4. Аналітика

На окремому екрані Dashboard відображаються:

- загальна кількість завдань;
- кількість виконаних завдань;
- кількість невиконаних завдань;
- кількість прострочених завдань;
- відсоток продуктивності;
- середній час виконання завдань.

### Призначення основних компонентів

| Файл | Призначення |
|---|---|
| `main.dart` | Ініціалізація застосунку, Hive, залежностей та навігації |
| `task.dart` | Модель завдання та перетворення даних |
| `task_adapter.dart` | Адаптер Hive для моделі Task |
| `hive_manager.dart` | Ініціалізація локального сховища |
| `task_repository.dart` | CRUD-операції, фільтрація та сортування |
| `backup_service.dart` | Експорт, імпорт і керування резервними копіями |
| `analytics_service.dart` | Розрахунок статистики |
| `home_screen.dart` | Головний екран керування завданнями |
| `dashboard_screen.dart` | Екран аналітики |
| `backups_screen.dart` | Екран резервного копіювання |
| `statistics_card.dart` | Віджет статистичних показників |
