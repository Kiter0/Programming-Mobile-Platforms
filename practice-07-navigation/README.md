# Практична робота №7 — Навігація у Flutter

## Варіант: №4 — «Кінотеатр»

## Тема

**Навігація між екранами, маршрутизація та deep links у Flutter за допомогою `go_router`.**

## Мета роботи

Ознайомитися з декларативною навігацією у Flutter, навчитися створювати іменовані маршрути, передавати параметри між екранами, налаштовувати захист сторінок залежно від ролі користувача та обробляти зовнішні посилання.

## Опис проєкту

Розроблено демонстраційний застосунок кінотеатру. Користувач може переглядати афішу, відкривати сторінки фільмів, переглядати розклад сеансів, обирати місця в залі та оформлювати квитки. Для навігації між основними розділами використовується нижня панель.

## Реалізовані можливості

- Афіша з переліком фільмів і можливістю вибору дати.
- Сторінка фільму з описом, рейтингом, тривалістю та розкладом сеансів.
- Вибір місць у залі та розрахунок загальної вартості.
- Оформлення квитків і перегляд списку придбаних квитків.
- Вхід у демонстраційні облікові записи користувача й адміністратора.
- Обмеження доступу до захищених маршрутів залежно від ролі.
- Нижня навігація з трьома розділами: афіша, мої квитки та профіль.
- Підтвердження виходу зі сторінки вибору місць, якщо вибір ще не збережений.
- Сторінка для невідомих маршрутів.
- Deep link для відкриття конкретного фільму: `cinema://app/movies/1`.

> Примітка: авторизація демонстраційна, без сервера та реальної перевірки облікових даних. Придбані квитки зберігаються в пам'яті під час роботи застосунку й не зберігаються після його перезапуску. Вибрана дата наразі відображається в інтерфейсі, але розклад сеансів не фільтрується за датою.

## Карта маршрутів

| Маршрут | Призначення | Доступ |
|---|---|---|
| `/` | Перенаправлення до афіші | Усі |
| `/movies` | Афіша фільмів | Усі |
| `/movies/:movieId` | Деталі фільму | Усі |
| `/movies/:movieId/session/:sessionId/seats` | Вибір місць і купівля квитків | Авторизовані користувачі |
| `/tickets` | Перегляд придбаних квитків | Авторизовані користувачі |
| `/profile` | Профіль користувача | Усі |
| `/login` | Екран входу | Усі |
| `/admin` | Панель адміністратора | Лише адміністратор |

Для основних розділів використовується `StatefulShellRoute.indexedStack`, що дає змогу зберігати стан вкладок під час перемикання. Параметр шляху використовується для ідентифікатора фільму, а параметр запиту — для передавання вибраної дати. Для переходу на екран вибору місць використовується `context.push`, а для повернення результату — `context.pop`.

## Перевірка deep link

У проєкті зареєстрована схема `cinema` для Android та iOS.

Приклад посилання:

```text
cinema://app/movies/1
```

На Android-емуляторі після встановлення застосунку можна виконати:

```powershell
& "D:\Android\Sdk\platform-tools\adb.exe" shell am start -a android.intent.action.VIEW -d "cinema://app/movies/1"
```

Очікуваний результат — відкриття сторінки фільму з ідентифікатором `1`.

Для іншого середовища шлях до `adb` може відрізнятися. На iOS потрібно зібрати й запустити застосунок на сумісному пристрої або симуляторі.
