# Практична робота №10
## Частина 1. Збереження даних у файловій системі

**Тема:** Робота з файловою системою у Flutter.

**Варіант 3:** Менеджер нотаток.

## Мета роботи

Ознайомитися з можливостями Flutter для роботи з файловою системою, навчитися створювати, читати, редагувати, перейменовувати та видаляти файли, а також реалізувати збереження даних і пошук інформації.

## Опис проєкту

Розроблено мобільний застосунок «Менеджер нотаток», який дозволяє створювати та зберігати текстові нотатки, редагувати їхній вміст, перейменовувати та видаляти записи.

Застосунок має графічний інтерфейс із переліком нотаток, пошуком, фільтрацією за датою та можливістю експорту інформації у формат JSON.

Передбачено підтримку двох способів збереження:
- **Windows:** збереження нотаток у текстових файлах `.txt` за допомогою `path_provider` та `dart:io`.
- **Web:** збереження нотаток у браузерному сховищі за допомогою `shared_preferences`.

## Реалізований функціонал

- Створення нових нотаток із назвою та текстом.
- Перегляд списку збережених нотаток.
- Редагування вмісту нотаток.
- Перейменування нотаток.
- Видалення нотаток.
- Перегляд розміру нотатки.
- Відображення дати останньої модифікації.
- Пошук нотаток за назвою та вмістом.
- Фільтрація нотаток за датою.
- Експорт нотаток у формат JSON.
- Копіювання JSON у буфер обміну.
- Обробка помилок під час роботи зі сховищем.

## Використані технології

| Технологія | Призначення |

## Запуск проєкту

1. Клонувати репозиторій або відкрити папку проєкту.
2. Встановити залежності:

```bash
flutter pub get
```

3. Запустити застосунок у Chrome:

```bash
flutter run -d chrome
```

Для запуску Windows-версії:

```bash
flutter run -d windows
```

## Перевірка якості коду

Для перевірки коду використовувалася команда:

```bash
flutter analyze
```

Для запуску тестів:

```bash
flutter test
```
